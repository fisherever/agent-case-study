# demands_agent 案例集公网化优化设计

> 日期：2026-07-29
> 目标：把案例集从"内部复盘文档"转成"个人作品集项目页"，服务求职/招聘场景。

## 背景

当前站点（https://fisherever.github.io/agent-case-study/README.html）读起来像对内草稿，不像面向大众的作品集。具体问题：

1. **README 是维护笔记口吻**：开篇"深度复盘"、"用途：个人作品集/简历素材来源"、"脱敏说明"、"HTML版本说明"、"文风：对标 agents/研究/"——这些是写给自己/团队的，外部读者不需要，且"简历素材来源"直接暴露动机。
2. **00 首屏被"诚实版"削弱**：判断一的"还没做透的理想"占了 2/3 篇幅，招聘者 30 秒内被"我其实没做到"击中，第一印象受损。
3. **无作者存在感和作品集框架**：没有署名、没有项目卡片、视觉上是一长篇文档。

## 已确认的决策

| 决策点 | 选择 |
|---|---|
| 服务对象 | 作品集/求职导向 |
| 00 首屏诚实度 | 恢复锐度，诚实后置（移到 03/06） |
| 改动范围 | 文案 + 有限视觉升级（不换技术栈） |
| Hero 风格 | 深色 hero（冲击强） |
| 目录展示 | 卡片网格（2列，每篇含编号/标题/一句话/阅读时间） |
| 署名 | fisherever + "个人独立项目" |

## 设计

### A. README 重写为"作品集封面"

**砍掉**（移到文末折叠的"关于"小节或删除）：
- "用途：个人作品集/简历素材来源"
- "脱敏说明"整节
- "关于 HTML 版本"整节
- "文风：对标 agents/研究/"等元信息
- "快速判断要不要读"那张对内表格（被 hero + 卡片目录取代）

**新增/重写**（自上而下）：

1. **深色 Hero 区**（CSS 实现，不引入构建工具）
   - eyebrow: `fisherever`
   - 大标题: `让 AI 在交付这件事上不撒谎`
   - 副标题: `一个数据需求 Agent 的工程实践`

2. **项目卡片**（紧接 hero，浅色卡片块）
   - 角色：独立设计与开发

   - 技术栈：Python · Typer · Nebula 血缘 · StarRocks/Hive/Presto（用 tag 标签样式）

3. **目录卡片网格**（2列，每篇一个卡片）
   - 每卡片：编号色块 + 标题 + 一句话 + 阅读时间

   - 这是什么、怎么做的（md→html 转换器）、脱敏说明（精简版）

### B. 00 电梯演讲首屏恢复锐度

**判断一**改回简洁版（删掉"还没做透的理想"整段）：

> **判断一：价值住在"验证"里，不住在"生成"里。**
> 生成能力会被下一代模型碾压，验证能力随模型变强而增值。判别工具是一个过滤器：假设 worker 无限聪明且诚实，这段代码还需要吗？需要的进 kernel/contract（升值），不需要的进 scaffolding（标注退役条件）。

**诚实后置**（保持可信度，但不破坏首屏）：
- 03 法则 1 已经有"诚实版"展开，保留不动。
- 06 收获与边界已有限制讨论，保留不动。
- 00 判断一不再重复诚实声明（避免首屏自我削弱）。

**00 文末阅读建议**改写：把裸 wikilink 列表改成"继续阅读"卡片样式，更自然。

### C. CSS 视觉升级（在 build_html.mjs 的 CSS 块内）

1. **`.hero` 深色区样式**：深色背景（#1a1a1a 系）+ 白字 + 内边距 + 大标题字号
2. **`.project-card`**：浅色卡片，带边框，技术栈用 `.tag` 标签
3. **`.toc-grid`**：CSS grid 2 列，`.toc-card` 每卡片含编号色块
4. **`.continue-reading`**：底部导航卡片样式
5. 保留现有所有样式（blockquote/code/mermaid/lightbox 等不动）

### D. 转换器适配

README 因为结构变化大（hero/卡片/网格），普通 markdown 表达不了，需要：
- **方案**：README 用 HTML 直写（特殊处理），其他 7 篇仍走 md→html 自动转换。
- build_html.mjs 检测到 `README.md` 时，如果是特殊标记的版本，直接用预写的 HTML 模板；否则走正常转换。
- 或者：README.md 里用 HTML 标签直接写（markdown 兼容原生 HTML），marked 会保留这些标签。

**采用后者**：README.md 里直接用 `<div class="hero">` 等 HTML 标签，marked 原样保留，CSS 负责渲染。这样仍保持单一 md 源。

- 不加导航栏/暗色模式切换/搜索（YAGNI）
- 不改真名署名（用 fisherever）
- 不删除 03 法则 1 和 06 的诚实讨论（它们在后置位置是加分的）
