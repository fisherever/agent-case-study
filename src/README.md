# demands_agent 案例集

> 一个数据需求自动分析与实现 Agent 的深度复盘。
> 用途：个人作品集 / 简历素材来源。不是代码搬运，是从项目中提炼的工程经验与方法论。

## 这是什么

这是一份关于 demands_agent 项目的分层案例集。demands_agent 是一个**把"数据需求从口述到上线"做成可验证交付流水线的内部 Agent**——它真正解决的问题不是"让 LLM 写 SQL"，而是"怎么让一个会写 SQL 的 AI 不在交付这件事上撒谎"。

这份案例集不复制代码，而是提炼：项目的设计思想、工程结构、可迁移的方法论、真实事故复盘、版本演进。目标是作为个人网站项目 / 简历的素材来源。

- **简历摘录**：00 的"三个最锋利的判断" + 03 的"10 条法则"标题 + 04 的 PM 统计

## 一句话总结这个项目

> **不是让 AI 变得更可信，而是用工程边界让"AI 不可信"这件事变得可验证、可拦截、可恢复。**

## 关于 HTML 版本

案例集以 Markdown 为唯一源（Obsidian 友好，mermaid 原生渲染）。`_sampler/` 目录下有一个 HTML 样式参考样例（`07-什么是Agent.html`），用于评估对外展示时的排版效果，不属于日常维护内容。如需对外展示版本，可基于该 sampler 的样式手工或半自动转换。
