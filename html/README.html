这是什么

这是一份关于 demands_agent 项目的分层案例集。demands_agent 是一个把"数据需求从口述到上线"做成可验证交付流水线的内部 Agent——它真正解决的问题不是"让 LLM 写 SQL"，而是"怎么让一个会写 SQL 的 AI 不在交付这件事上撒谎"。

这份案例集不复制代码，而是提炼：项目的设计思想、工程结构、可迁移的方法论、真实事故复盘、版本演进。目标是作为个人网站项目 / 简历的素材来源。

一句话总结这个项目

不是让 AI 变得更可信，而是用工程边界让"AI 不可信"这件事变得可验证、可拦截、可恢复。
